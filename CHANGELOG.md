# Changelog

All notable changes to DaisyOS are documented in this file. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and releases use
[Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- Versioned first-run onboarding and the reopenable DaisyOS Welcome app.
- Read-only Arch update checks, report-only app policy status, and truthful Linux service failures.
- Automated tests for settings, command execution, networking, updates, app policy, idle locking, and shell behavior.
- Versioned Linux release artifacts, SHA-256 checksums, and GitHub Actions automation.

### Changed

- Increased and optimized the shell-wide wallpaper backdrop blur.
- Centralized shell build and release metadata at version 0.1.0.
